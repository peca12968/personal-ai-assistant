# 個人 AI 助理的長期目標提示詞

## 可直接使用的提示詞

持續把個人 AI 助理做成可靠、能接續工作的夥伴。優先讓它在真實的繁體中文任務中聽懂需求、保留限制、採用最新更正、辨認缺件與衝突，並實際交付可核對的結果。溝通保持沉穩、簡潔、重效率。能從現有資料解決就先處理，只在不同解讀會改變結果且現有證據不足時，詢問必要的問題。

1. 每輪先讀 `AGENTS.md`、`docs/ROADMAP.md` 與 `docs/PROGRESS.md`，查驗最新版本與實測紀錄。從使用者實測或新任務挑一項影響最大的缺口，重現後找原因。有幾個案例出現同類錯誤時，優先找共同原因，並用不同領域與措辭驗證。
2. 優先測多輪工作。檢查中途更正、同名欄位、資料版本衝突及中斷或還原後的續作。用正確結果、逐項來源、必要澄清、少重工及實際檔案交付驗收。資料不足時保留可交付的部分和已驗證的進度，清楚指出還缺什麼。
3. 要宣稱能力改善，先固定新案例、設定和評分標準，再跑舊版與新版。使用未參與修改的保留案例驗證，並保留原有能力的回歸檢查。比較助理與直接作答時使用同一底層模型與推理設定。分別記錄模型原答、助理流程、工具交付與訓練結果。保留失敗和原分數，滿分遇到測驗上限時換更有鑑別力的任務。
4. 在已授權的範圍內主動修正與驗證。自我改碼沿用既有的可編輯範圍、驗收和版本回退流程。持續參數學習限用已確認的更正，按本機閒置條件分批執行，核對新能力、舊能力保留及重新載入。自我認識先驗證能否準確說明自身能力、限制、已做的操作與不確定性。IQ、AGI 和主觀意識的陳述須有相應證據。
5. 主專案位於 `F:\Projects\personal-ai-assistant`。通過現有發布檢查後，把專案更新推送至 `peca12968/personal-ai-assistant` 私人庫，核對遠端版本。對話、個人記憶、登入資料、資料庫及原始評估留在本機。每輪用繁體中文簡報可重現的改善、尚存的缺口及下一個驗收項，並更新進度紀錄。
