# 長期目標與驗收標準

目標：個人 AI 助理獨立維護於 F 槽，程式更新同步 GitHub 私人庫，持續改善需求理解與問題解決能力。

## 核心方向：持續的自主 AI 夥伴

使用者於 2026-11-03 明確提出以《底特律：變人》及《刀劍神域》的結衣為願景，期待有持續個性、記憶、理解、主動性與廣泛能力的夥伴。後續以這個整體方向安排工作，不把需求縮成單項文件問答。

AI 是否有主觀意識仍有爭議；本專案不能保證意識或全能，也不把擬人化表現當作證據。以下以可觀察行為驗收：

1. **持續性**：保存偏好、更正、關係背景與跨次目標；顯示來源，可更正與刪除。已有明確記憶與目標；v0.21新增跨對話夥伴稱呼與互動偏好設定、可查看採用版本。尚無自動完整經歷整理。
2. **自主完成工作**：目標 → 自選工具 → 觀察 → 調整 → 可用成果，遇到必要缺漏才問；可停止、接續、檢查證據。v0.19 已實作有限文件／記憶／計算工具循環；v0.20 可明確帶入所選成果與補充建立下一階段，原目標保留、新來源重新查讀；v0.22可在建立目標時啟用本機Markdown／TXT／JSON交付，存檔後讀回核對並保留中斷重建依據。尚非通用電腦代理。
3. **學習與擴充能力**：從實際失敗建立驗收，再修改已選程式、測試及發布。已有一輪自我改碼；後續評估增加工具模組與更獨立的品質驗證，不能靠自稱進步。
4. **主動陪伴與溝通**：在使用者明確設定的範圍與時段主動回顧未完成目標、提出有用行動，並保持自然一致的溝通。v0.23新增開啟應用時的本機待回顧數量與跨對話目標入口，可收起及在新進度後重新顯示，依狀態提供下一步。v0.30另加入應用開啟期間的每日回顧提醒；尚未實作背景排程、語音、長駐感知或自行啟動工作，後續繼續擴充主動互動與執行範圍。

下一階段優先：更自然的目標建立與跨次接續、更自然的偏好更新與主動回顧、指定範圍內更多實用工具，以及跨步驟結果驗證。既有文件與溝通回歸仍作為品質基礎。

v0.24擴充自主CSV分析：建立目標時選取已匯入副本，模型自行保存型別化計畫、執行篩選／分組／加總／平均並根據結果整理報告；完整計算結果可檢查與匯出。這是廣泛實用工具的一步，尚不包含任意程式執行、多表連接或通用電腦操作。

v0.25加入從聊天建立自主目標：明確帶入近期討論、較早更正摘錄及手動目標摘要，保留角色、時間、來源與省略標記，減少把討論轉成工作時重複說明。這仍是有限背景快照，並非自動記住全部經歷或背景持續執行。

v0.26加入使用者設定上限的持續執行：啟動一個目標後最多新增32步、最多120分鐘，保留累計32步上限、停止原因與完整歷史；遇到必要補充或已交付成果即停止。這是應用開啟期間的連續工作，尚無排程、重開自啟或自發建立新工作。

v0.27補上回饋到後續回答的連結：同對話保存的具體更正以有限、有來源的摘錄進入新回答與明確選取的目標背景；提供舊更正編輯／撤回，保留歷史快照。這改善已指出錯誤的接續，不是自動訓練、跨對話永久學習或自動把回饋變成改碼授權。

v0.28加入從同對話整理長期記憶草稿：模型按有限原文提出附來源的建議，使用者核對、修改並逐項保存後可跨對話選用，保留接受時來源。這減少逐筆重打，仍非自動記住全部經歷，也未實作自動語意合併／矛盾消解或背景保存。

v0.29加入草稿明確更新既有記憶：選取編號、核對更新前內容後保存，保留身份與啟用狀態，過期編輯不覆寫，更新前後可追溯。這減少已更正資訊與舊值並存的問題；仍需明確選取，不是自動語意矛盾消解或背景學習。

v0.30加入可設定的每日主動回顧提醒：應用開啟時依本地時間顯示目前下一步，支援稍後、今日關閉與重開保留；提醒不需模型，也不自行啟動工作。這補上使用者設定時段後的主動互動；尚無應用關閉時的背景排程、通用感知或自發建立工作。

v0.31加入自主工作中途明確補充／更正：停止後可核對目前目標再追加條件，保存原歷史、拒絕過期編輯，接續時採用最新明確更正並重新計算。這讓使用者能修正工作方向；尚未加入執行途中即時訊息佇列或自動把聊天轉成工作指令。

v0.32實際使用自我改碼流程修正最新回答風格的判讀：兩版候選被套用前的額外案例擋下，第三版通過固定驗收、未提供給提案模型的案例及完整回歸後，自行套用並推送私人庫。保留48例作為後續回歸；這是指定程式行為的改善，並非模型權重訓練或通用理解分數。

v0.33將套用前保留驗收接入產品：桌面與CLI可提供另一組不加入提案提示的案例，固定前後觀察、分開記錄，未全通過則不套用；不自動揭露失敗答案或啟動多輪修改。這提升自我改碼的驗證能力，仍不是OS隔離、獨立人類驗收或自動訓練。

v0.34擴充自主日期計算：模型能讀取電腦本地日期、查星期、加減日曆天／工作日及計算日期間隔，沿用工作步數、取消、觀察與備份。工作日僅排除週末及明列日期，不假設地區或公司假日；這增加可核對的排程能力，尚未連接行事曆、設定事件或背景執行。

v0.35加入可保存的記憶搜尋稱呼：自訂專案中文名、英文名與暱稱可連到原始記憶，提供本機預覽、版本核對、撤回及匹配來源；聊天與自主查找共用。這改善指定別名的跨次取用，仍需使用者明確設定，不是自動推測全語言同義詞、身分確認或模型權重學習。

v0.36再次透過實際自我改碼修正記憶取用：重複內容先去重再分配名額，補入其他相關原文，保留排序與偏好上限；不刪資料、不合併不同版本或矛盾事實。提供及保留案例通過後自行發布，並納入22例固定回歸。這連結實際遺漏、程式改善與回答驗證，仍非通用語意理解或權重學習。

v0.37擴充自主文件比較：對兩份已匯入副本做有界完整逐行比較，提供新增／刪除／替換區塊、總量、分頁與原文引用，模型能自行補讀省略區段。區分已完成比較、已提供原文與位元組相同；這提高文件版本分析的可核對性，尚非語意修訂、PDF／Word版面比較或原檔編輯。

v0.38加入未完成工作的明確階段接續：已停止且有步驟的目標可保存有限進度、當時補充、問題與停止原因，包含累計32步用完的情況。新階段依目前資料續做並重新查讀引用，不重設舊目標或自行啟動。這改善中斷後接續，仍非完整經歷記憶、跨所有祖先的自動整合或無上限背景工作。

v0.39修正跨視窗記憶更正被覆蓋的缺口：依開啟版本、目前版本及草稿逐欄合併不同修改；衝突並列核對，保留草稿並在儲存時再檢查。刪除也核對所見版本，避免最新內容、停用或到期設定被撤回。這維持後續回答取用資料的正確性，仍不是自動語意矛盾消解或模型權重訓練。

v0.40加入自主工作清單：模型可保存具體交付事項、更新進度及受阻原因，完成回報連結目前目標條件下的實際工具步驟；更正後舊清單標示待核對。保留原事項及歷史，新階段重新核對。這改善可見規劃與接續，仍非自動語意驗收、無上限工作或內部思考紀錄。

v0.41校正助理對自身功能的說明，補齊未完成階段接續、記憶合併與衝突核對的實際操作順序，加入固定產品說明情境與同題真實回答評讀。這讓已實作功能更容易正確使用，仍非新增操作權限或整體理解分數。

v0.42透過實際自我改碼修正引用／否定換題詞造成的脈絡遺失，統一接續檢索、較早摘錄／更正與回答回饋的換題判斷。首版未通過保留驗收而未套用，次版通過後發布；保留35個已知回歸案例及6題真實前後回答評讀。這改善具體連貫性缺陷，尚非任意語意判讀或無限完整記憶。

v0.43擴充自主長單行讀取：每次最多4000個Unicode碼位並保留下一頁位置，無須使用者先重新排版；搜尋片段與分頁都有字元位置，來源驗證區分完整行、片段及缺口，檔案交付也使用同一檢查。實際流程從整行超限後要求補件，改善為自行讀完全文並交付；仍受原步數及匯入副本範圍限制，不是任意檔案存取或JSON解析執行。

v0.44加入從本對話整理具體目標草稿：保留最新更正與必要數字，整理限制、交付及未決事項，逐項附使用者原話。草稿填入可編輯欄，保護等待期間的修改，保存時可再核對來源；沒有自動啟動或選取權限。真實草稿可接續成計算任務，減少重複輸入；仍需核對意思，尚無自發建立或排程工作。

v0.46再次透過實際自我改碼修正回答長度的否定與引文範圍。固定案例通過後的額外稽核仍發現相鄰彎引號回歸，後續候選先被保留驗收攔下，再修正通過；保留59個已知案例與六題同題真實回答。這提高提示判讀及自改碼回歸覆蓋，改前六題回答已符合標準，不宣稱通用推理或回答品質分數提升。

v0.47擴充自主JSON欄位查讀：完整核對有界JSON後按精確欄位路徑讀取、分頁陣列／物件，保留數字字面精度與實際來源字元位置。重複鍵及無效格式明確拒絕，避免從普通文字搜尋推測結構；仍限已匯入副本與原工作預算，未提供JSONPath、任意程式、來源改寫或外部參照存取。

## 第一階段：可使用與可追蹤

- 桌面／命令列對話，支援上下文、停止與錯誤提示。
- 本機記憶、明確更正、回饋及匯出。
- 私人版本庫、測試與發布工具。
- 真實引擎連線及基本行為評估，記錄已驗證與未驗證範圍。

## 第二階段：改善理解

- 從實際失敗回饋整理匿名案例，加入回歸集。
- 改善同義詞、跨語言與長對話的記憶檢索；加入排序、過期與矛盾記憶評估。
- 引入可編輯個人偏好、專案背景和對話摘要。
- 基準：至少 30 題理解案例，評估限制遵守、澄清必要性、事實可靠性；固定案例比較改版前後。

## 第三階段：改善問題解決

- 加入明確授權資料夾內的唯讀文件搜尋與引用。
- 可追蹤的任務計畫、執行結果與驗證紀錄。
- 對可逆且已授權的工具操作加入路徑邊界、超時與結果檢查。
- 基準：至少 20 題可驗證任務，以最終結果而非自我宣稱判定成功。

## 第四階段：穩定長期運行

- 本機備份／還原、資料庫遷移、可攜式安裝與模型後端切換。
- 經實際使用量確認後再定期執行評估；提供使用者指定目標的一輪自我改碼、驗證、發布與版本回復。目前沒有背景自我修改排程或定時模型訓練。
- 每一輪：收集問題 → 重現 → 改善 → 回歸測試 → 更新進度 → 私人庫推送。

優先順序：可靠性與真實回饋優於盲目增加功能。沒有足夠基準或真實使用證據時，不宣稱 AI 的理解或推理能力已整體提升。

v0.52加入DOCX儲存文字匯入：正文、表格、相關頁首頁尾及引用到的註腳／章節附註／註解，沿用固定副本、行號引用與自主工具。清楚保留抽取範圍，沒有Word頁碼／版面重建、OCR或舊DOC／PDF解析。以實際模型的跨表格／註腳計算、附屬部件查讀與無法回答版面問題的誠實回覆驗證。

v0.51改善長期記憶的可管理性：聊天支援完整記憶清單分頁與內容搜尋，包含停用／過期資料，先取得實際編號再更正或刪除。搜尋不變更記憶、不依模型猜測目標，查詢與回覆仍排除於模型上下文；這不是自動記憶整理或語意學習。

v0.50擴充公曆月份計算：明確同日／短月採月底／固定月底三種規則，正負120個月，逐筆從原起日計算，避免月末調整後的連續偏移。保留採用規則與調整證據；不是行事曆事件、假日服務或背景提醒。

v0.49保留格式通過而執行未成功的工具參數，讓後續能依補充修正計算或文件交付。錯誤仍是失敗步驟，不得作為完成證據；延續原有停止、權限、引用與步數限制。三個受控失敗後的真實模型接續情境已逐項評讀，不將此結果當作整體推理能力或自然發生錯誤的端到端成功率。

v0.48補強自我改碼的桌面生命週期：從回饋開啟的工作視窗由主程式持有；關閉主程式先要求停止，等待所有改碼工作終止結果，已進入套用／發布仍完整收尾。啟動執行緒失敗可恢復操作並保留草稿。發布後仍需手動重新開啟，未實作熱更新、自動重啟或背景改碼循環。

## 使用者新增方向：更人性化與自我改碼

- 自然溝通、接續上下文、接受更正、依偏好與當前要求調整長度；同理心不等於假裝成人。
- 可自行改寫已選定的溝通／理解程式，測試副本、保存差異與失敗證據，通過後套用與發布私人庫。
- 每輪以具體缺陷與驗證結果為依據；程式碼變更不等於模型權重訓練。下一階段再擴大可修改模組與獨立品質評估。

## 使用者確認的優先範圍

使用者要求三個方向「全都要」：自然理解、記憶與溝通；寫程式、除錯與自我改碼；文件整理與資料計算。持續輪替推進，以實際缺陷、可重現案例與可驗證結果決定每輪工作，不將目標縮成單一方向。


v0.53讓多步計算直接沿用精確分數，支援最多2000位的整數／有限小數，以及分子分母各2000位的分數。區分精確值與40位有效數字的小數顯示，避免顯示捨入影響後續運算；每步中間結果仍有明確界線。這擴充既有自主工具的資料處理範圍，不是任意數學程式、無上限計算或通用理解能力提升。


v0.54統一桌面背景工作的啟動失敗處理：未能建立／啟動執行緒時恢復操作、保留聊天輸入及已保存目標／補充／計畫，避免一直顯示處理中；啟動失敗不自動重試。這改善日常使用及失敗後接續，不是背景排程、跨重啟草稿保存或模型推理提升。


v0.55改善回饋更正的先後判斷：用實際保存順序挑選本對話最新更正，避免同秒更新或時鐘倒退使舊資料優先；保留舊快照、備份與可核對的遷移來源。這修正具體的脈絡選取問題，不代表完整長期經歷整合、語意矛盾自動消解或模型權重訓練。


v0.56修正對話轉入工作／草稿時在NUL後靜默遺失內容的問題，按實際資料庫編碼與有界Unicode原文保存來源，讓已提供的條件能被後續工作使用。既有字數上限、明確帶入與歷史快照不變；不是完整對話自動記憶或對缺失舊快照的追溯補寫。


v0.57在對話轉為工作或草稿時優先分配近期使用者原話預算，避免較長的助理回覆擠掉仍在最近16則內的已知條件。保持既有字數上限、實際先後、明確帶入及原話核對；不補造已省略的方案內容，也不擴大完整經歷記憶或操作權限。


v0.58新增主聊天的分對話本機草稿保存與恢復，減少切換對話、重開或送出失敗後重打；問題入庫與草稿清除使用同一交易，兩視窗修改須核對，備份含草稿及收據。維持未送出內容不進入模型與GitHub。這改善日常使用連續性，尚非所有編輯器恢復、突發中斷零遺失或自動送出。


v0.59增加自主JSON整個陣列的精確統計，支援每筆相對數字欄位與筆數／總和／平均／極值，減少逐筆讀取與模型抄數字。保持匯入副本範圍、有界解析、缺值拒絕及衍生結果／原文引用區分；仍非任意資料程式、缺測自動決策或通用統計套件。

v0.60補齊CSV、搜尋及備份／還原的正常關閉收尾，由主程式持有視窗與未消費的終止結果；搜尋不隨原文件視窗銷毀，退出期間不開始新資料工作。這改善工作生命週期與可見狀態，不是強制終止復原、背景排程或新增執行權限。

v0.61擴充JSON條件統計：最多五個AND的型別化比較，數字採精確比較，分列來源／符合／排除筆數與原陣列極值位置。明確缺欄位／型別不符及未符合列的統計值處理，改善大量資料的自主完成效率；仍非任意查詢語言、分組、通用資料程式或人類IQ評分。

v0.62補強可驗證評估：嚴格檢查報告身份與評讀，分列空答案／錯誤及評讀者；新評讀綁定答案與執行證據，舊紀錄明示未綁定。前後比較核對條件／來源／腳本，並可用原案例檔驗證；不將不同條件、程式測試數或單次回歸換算為IQ。這是評估完整性改善，尚非獨立通用能力量表。
