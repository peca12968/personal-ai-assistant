# 同模型推理對照測驗

這套測驗比較「相同模型直接作答」與「經過個人助理聊天流程作答」。它使用原創、可核對答案的文字題，沒有經人類常模校準，不能換算人類IQ、年齡或百分位，也不能證明意識或一般智能高低。

## 固定條件

- 36個不同題目：邏輯推論、數量推理、空間符號、順序與條件追蹤、排列約束、規則歸納各6題。每邊重複兩輪，共72個題次；含同類模板變體，不假設題目統計獨立，重複題也不當成新增獨立樣本。
- 每次6題，六類各一題；每輪相同題目和批次。兩邊取得相同的公開題目及最終答案格式，不提供答案鍵、推導證明或評分回饋。
- 兩邊透過相同Codex CLI，以相同的明確模型名稱、推理設定及240秒呼叫上限作答。每對呼叫並行，交替提交順序；耗時包含本機啟動、助理上下文處理及服務排隊，不當成人類處理速度。
- 直接組僅送公開題目；助理組使用真正的Assistant.ask、全新合成資料庫及direct風格。沒有私人記憶、舊對話、附件或自主工具，並非完整個人助理實用能力測試。
- 沿用正式引擎的唯讀、停用搜尋／shell／apps／plugins等限制與ephemeral工作模式；不給任一方額外計算工具。直接組仍含Codex CLI的共同環境，不能冒稱ChatGPT網站成績或裸API基準。
- 每次核對CLI公開標頭的model及reasoning effort，缺漏或不符列為執行錯誤，不偷偷更換模型。這是CLI所記錄的設定，並非服務內部模型身份認證。

## 題庫與評分

`scripts/reasoning_cases.py`以固定seed產生題目、答案鍵及核對資料。邏輯用有限真值枚舉；排列用全部排列確認唯一解；歸納明列有限係數範圍並驗證唯一規則，避免無窮種數列規則的歧義。空間題是明確座標與矩陣的文字轉換，不能代表完整視覺智力測驗；條件追蹤的輸入持續可見，也不是人類工作記憶常模測試。

答案鍵及程式／提示／模型設定的指紋在首次作答前保存。模型只收到白名單投影的id與prompt；沒有任意讀取工作區工具或答案鍵注入。測試期間不修改助理、題目或評分，也不根據結果重試挑最佳答案。

評分不請模型自評，每題每輪等權：數值以精確Fraction比較，接受等價整數、小數與分數；序列和方格按明定結構核對；邏輯選項固定為必真／必假／不確定。允許單一完整json程式區塊包住回答，但不從混雜解釋中猜測答案。重複JSON鍵、未知鍵、非物件及NaN拒絕；缺題或無效答案格式另列。明確「無法作答」單列，不當格式錯誤。錯答、格式缺漏、棄答及執行錯誤都不取得正確分，但原因分開保存。

摘要重新依原始回答核對分數與案例身份，拒絕重複批次、分數改寫或未收齊卻標完整。兩輪答案一致率可以包含兩輪同樣答錯，不能當正確率。若兩邊滿分，表示這套題無法區分其能力，不能推論一般智能相同或更高。小樣本差異亦不單獨證明普遍優勢。

測驗由開發代理設計，未經獨立心理計量驗證；原創生成不保證模型訓練中從未看過同類形式。發布後這些生成規則屬已知回歸材料，後續能力提升需要另外設計未用於修改的測試，保留既有成績。

## 執行與保存

僅驗證題庫，不呼叫模型、不建立輸出資料夾：

```powershell
.\.venv\Scripts\python.exe scripts/evaluate_reasoning_pair.py --out data/evaluations/check
```

正式測量（必須使用不存在的新目錄）：

```powershell
.\.venv\Scripts\python.exe scripts/evaluate_reasoning_pair.py --live --model gpt-6.1-sol --effort medium --out data/evaluations/新的測量
```

輸出report.json保存固定題庫／答案鍵、實際送入提示、原始回答、逐題狀態及CLI公開模型設定；summary.json保存統計，RESULTS.md供閱讀。此為獨立對照格式，不是既有單次理解報告，不可直接放進v0.63報告檢視器。執行錯誤停止後保留不完整結果，不自動重試或宣稱完整測量。觀察逾時不等於原程序已停止，須核對原工作handle。

所有原始回答、合成資料庫及執行日誌都只留忽略的data目錄，不上傳GitHub。可提交生成器、測量程式、測試及匿名彙總方法紀錄。此流程不更改正式助理模型設定、提示或使用者資料。

方法參照[OpenAI評估建議](https://developers.openai.com/api/docs/guides/evaluation-best-practices)：以具體任務與可核對標準評估，將測量與人類判斷結合。CLI參數依[官方命令參考](https://learn.chatgpt.com/docs/developer-commands?surface=cli)及本機版本的help核對。
